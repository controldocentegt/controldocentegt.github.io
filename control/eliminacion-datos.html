Solicitud de Eliminación de Datos

🗓 Última actualización: Mayo 2026

Cuentas de Usuario

Control Docente GT no crea cuentas de usuario tradicionales.

La aplicación solo almacena la siguiente información de forma centralizada:

  • Código de licencia de activación
  • Identificadores de equipo
  • Fecha de activación

Proceso de Eliminación

Los usuarios que deseen que se eliminen sus datos de activación pueden enviar una solicitud formal a nuestro equipo de soporte.

Los datos solicitados se eliminarán dentro de un período de tiempo razonable, a menos que se requiera su retención por motivos legales o de seguridad.

Contacto para Solicitudes

Para enviar una solicitud de eliminación de datos, por favor contáctanos al siguiente correo electrónico:
